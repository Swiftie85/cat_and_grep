# Simple Bash Utils

Реализация утилит `cat` и `grep` на языке C для работы с текстовыми файлами в терминале Linux.

## Описание проекта

В проекте реализованы аналоги стандартных Unix-утилит `cat` и `grep`. Программы работают с аргументами командной строки, поддерживают основные флаги соответствующих утилит и собираются с помощью `Makefile`.

Реализация выполнена на языке C стандарта C11 с учетом требований POSIX.1-2017 и принципов структурного программирования.

## Реализованные возможности

### `s21_cat`

Реализован аналог утилиты `cat` с поддержкой следующих флагов:

| Опция | Описание |
| ------ | ------ |
| `-b` | Нумерация только непустых строк |
| `-e` | Отображение символов конца строки как `$` и непечатаемых символов |
| `-E` | Отображение символов конца строки как `$` |
| `-n` | Нумерация всех выходных строк |
| `-s` | Сжатие нескольких последовательных пустых строк |
| `-t` | Отображение табуляции как `^I` и непечатаемых символов |

Поддерживается запуск как с флагами, так и без них.

Исходные и заголовочные файлы находятся в `src/cat/`. Исполняемый файл собирается как `src/cat/s21_cat`.

### `s21_grep`

Реализован аналог утилиты `grep` с поддержкой флагов:

| Опция | Описание |
| ------ | ------ |
| `-e` | Задание шаблона поиска |
| `-i` | Игнорирование регистра |
| `-v` | Инвертирование условия поиска |
| `-c` | Вывод количества совпадающих строк |
| `-l` | Вывод только имен файлов с совпадениями |
| `-n` | Вывод номеров строк |


Поддерживается запуск как с флагами, так и без них. Для работы с регулярными выражениями используются библиотеки `pcre2` или `regex`.

Исходные, заголовочные и Make-файлы находятся в `src/grep/`. Исполняемый файл собирается как `src/grep/s21_grep`.

## Структура проекта

```text
src/
├── cat/
│   ├── s21_cat.c
│   ├── ...
│   └── Makefile
└── grep/
    ├── s21_grep.c
    ├── ...
    └── Makefile
```

Общие компоненты при необходимости вынесены в отдельные модули и переиспользуются между утилитами.

## Сборка

Для сборки используются `Makefile` с целями:

```bash
make s21_cat
make s21_grep
```

Программы компилируются с использованием компилятора `gcc` и стандарта C11.

## Тестирование

Реализация проверяется интеграционными тестами путем сравнения поведения `s21_cat` и `s21_grep` с соответствующими системными утилитами.

Проект рассчитан на работу с аргументами командной строки и текстовыми файлами.
